ребования:

Эндпоинт
GET /status — отдаёт HTML-страницу
(Опционально) GET /api/status — отдаёт ту же информацию в JSON

Что должно отображаться на странице:
Статус сервера: Running
Время запуска сервера
Uptime (в удобном формате: часы и минуты)
IP-адрес сервера (локальный)
Общее количество слепков
Список всех слепков в виде таблицы или списка:
Название / ID слепка
Дата создания
Размер файла
Путь к JSON-файлу на диске
кнопка запуска сервера
кнопка остановки сервера


Технические детали:
Время запуска сервера сохранять при старте приложения (например, в переменную при инициализации).
IP-адрес получать автоматически (можно через socket).
Список слепков брать из базы данных + проверять наличие файла на диске (или только из файловой системы, если так сейчас устроено).
Страница должна быть простой, читаемой, без сложных зависимостей (чистый HTML + минимальный CSS).
Если слепков много — показывать хотя бы первые 100–200 и общее количество.

Дополнительно (по возможности):
Кнопка/ссылка «Обновить»
Цветовая индикация статуса (зелёный — Running)
